# موقع Amr Adel — نسخة مستقلة لاستضافتك

الكود الكامل للموقع: React، TypeScript، Vite، CSS، الصور، أيقونات الأدوات، بيانات البورتفوليو وملف تثبيت الإصدارات `package-lock.json`.

## تشغيل المشروع وتعديله

يلزم Node.js 22+ وnpm.

```sh
npm ci
npm run dev
```

## ضبط الدومين

استبدل الدومين المثال بدومينك الحقيقي:

```sh
npm run set-domain -- https://your-domain.com
npm run build
```

الأمر الأول يضبط canonical وOpen Graph وبيانات Person على الدومين الجديد. لم يتم وضع دومين افتراضي في النسخة المستقلة. يجب إعادة البناء بعد تغييره.

## الرفع على الاستضافة

`npm run build` ينتج مجلد `dist`.

- في cPanel: ارفع **محتويات** مجلد `dist` إلى مجلد جذر الدومين المحدد في لوحة التحكم، مثل `public_html`. احفظ نسخة احتياطية من أي موقع قائم قبل استبدال ملفاته.
- في Netlify أو Cloudflare Pages أو Vercel: أمر البناء `npm run build` ومجلد النشر `dist`.
- هذه نسخة static؛ لا يلزم تشغيل Node.js على استضافة cPanel بعد البناء.
- ملف `amr-adel-upload-ready.zip` يحتوي ملفات الإنتاج مباشرة في جذر الأرشيف. فك الضغط داخل مجلد جذر الدومين بعد ضبط DNS وHTTPS لدى مزود الاستضافة.

إذا رفعت الموقع داخل مجلد فرعي بدلاً من جذر الدومين، اضبط `VITE_BASE_PATH=/folder/` وقت البناء.

## تعديل المحتوى

- `src/data/portfolio.ts`: معلومات التواصل، الأرقام، أسماء البراندات، مصادر اللوجوهات، الخبرات، القدرات والأدوات.
- `src/App.tsx`: تركيب الأقسام، الخبرات المميزة، التعليم ونسخة BIMEX.
- `src/styles.css`: تصميم الموقع والموبايل.
- `public/amr-adel-portrait.webp`: الصورة بخلفية شفافة، محسّنة للويب.
- `public/icons/`: أيقونات الأدوات المحلية.
- `public/brands/`: الأصول المحلية للبراندات.
- `index.html`: العنوان والوصف وبيانات SEO.

روابط Email وCall وWhatsApp تعمل مباشرة. لا يوجد نموذج وهمي أو خادم مطلوب. LinkedIn يظهر فقط عند إضافة الرابط الصحيح في `profile.linkedin`.

## ملاحظات الأصول

صورة البورتريه أُعدت من الصورة التي أرسلها المستخدم عبر إزالة الخلفية بأداة تحرير الصور، ثم تحويلها إلى WebP.

ANTA وأيقونات الأدوات المحلية من Simple Icons. Skechers وUmbro من Wikimedia Commons، وRed Cotton من Brandfetch، وSouqpress من قائمة التطبيق الرسمية في Google Play؛ هذه الأربعة تُحمَّل من روابط خارجية موثّقة في `brandAssets`. يوجد بديل نصي إذا تعذّر تحميلها. يمكن استبدال الروابط بأصول محلية لاحقًا. البراندات الأخرى معروضة بأسمائها إلى أن تتوفر ملفات الشعارات الأصلية.

حقوق العلامات والشعارات لأصحابها، وعرضها يوضح الخبرة المهنية دون الإيحاء بتأييد الموقع. Inter تحت ترخيص SIL Open Font License، وLucide تحت ISC.

محتوى الخبرات والأرقام مأخوذ من الملخص الذي قدمه المستخدم؛ لم تُختلق تواريخ عمل أو نتائج إضافية.

## الاستقلالية

هذه النسخة تعمل على استضافتك الخاصة ولا تعتمد على خدمة Sites أو حساب ChatGPT. لا تحتوي أسرارًا أو بيانات دخول، ولا تتضمن إعدادات الاستضافة السابقة. تحديث النسخة المستقلة لا يغيّر الموقع المنشور سابقًا.
